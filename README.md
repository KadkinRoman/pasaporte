# Pasaporte

Игра для изучения языков в поездках: аргентинский испанский и американский английский с нуля.

Играть: https://kadkinroman.github.io/pasaporte/

Игра сохраняет прогресс в браузере. Чтобы продолжать с телефона на ПК,
откройте «Progreso» → «Связать устройства» и создайте код на устройстве с нужным прогрессом.
На втором устройстве введите этот код и подтвердите загрузку. Код личный, он даёт доступ к сохранению.
